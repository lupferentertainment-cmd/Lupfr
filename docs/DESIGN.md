# Design

**Product.** Marketing site for LUPFR Entertainment: hero, social proof (metrics carousel in the Reviews section), events list + event detail pages, services, artists, about, contact form, newsletter signup, footer. Single primary scroll on home; event detail is a dedicated route. Unknown URLs use `app/not-found.tsx` (brand logo from `/logos/will_logo.png`, nav + footer, link home).

**About.** The large horizontal text marquee that listed service phrases (boat parties, rooftop sessions, etc.) is **archived** (see `_deprecated/about-marquee.tsx`); it is not rendered on the live About section.

**Reviews.** The scrolling testimonial marquee (desktop three-layer + mobile single strip) is **archived** (`_deprecated/reviews-marquee.tsx` + `_deprecated/reviews-marquee.css`); the live section shows only the rotating metrics carousel. Metrics render as larger card tiles; on `(hover: hover)` + `(pointer: fine)` they tilt slightly toward the cursor (transform-only while the pointer moves). `prefers-reduced-motion` turns off tilt.

**Mobile performance (≤767px).** Hero uses a static grid/orbs (no continuous Motion loops), longer hero phrase rotation, muted inline hero video (`playsInline`, `preload="metadata"`) with `next/image` + the same poster as fallback on error or slow load, and a non-animated scroll hint. Reviews: slower stats carousel interval, no scroll-linked section fade (full opacity). Top scroll progress bar is omitted (and its Framer `useScroll` subtree does not mount, avoiding extra scroll-linked work). Breakpoint matches `hooks/use-mobile.ts` (`useLayoutEffect` for earlier, pre-paint width read).

**Scroll-driven motion (flicker avoidance).** Until `useIsMobile()` resolves (`undefined`), the site treats the viewport as **not desktop-confirmed**: hero uses the same lite path as mobile (static orbs, no parallax, `preload="metadata"` on hero videos), Reviews skips scroll-linked fade and uses the slower carousel interval, and the top scroll progress bar stays hidden. After mount, only `isMobile === false` (≥768px) enables desktop parallax, dual-video aggressive preload, scroll progress, and Reviews scroll fade. `ScrollReveal` uses one `motion.div` with scroll-linked opacity/transform from the first client paint (no interim plain `div` at full opacity). `GoldShineText` and the hero use `useScroll` with `layoutEffect: false` when the measured target is a parent ref, avoiding Framer “ref not yet hydrated” warnings under Strict Mode.

**Framer / dev console.** Motion-animated colors and shadows use `rgba`/`#hex` (not `oklch()` in `animate`/`whileHover`) so Framer can interpolate. Hero video hints use `<video preload>` only (no `react-dom` `preload` with `as: "video"`—React warns). The first event card uses `next/image` `priority`/`fetchPriority` instead of root `<link rel="preload">` for the raw file path (optimizer URL would not match).

**Scroll smoothness vs flicker.** `html { scroll-behavior: auto }` keeps wheel/trackpad scrolling in sync with Framer `useScroll` (native `smooth` fights scroll-linked opacity/transform). `ScrollReveal` renders scroll-driven motion immediately—no pre-mount plain `div` at full opacity (that caused a flash when switching to opacity 0 below the fold). Body omits long `background-color`/`color` transitions so theme and scroll motion don’t compound into visible shimmer.

**Content-driven sections.**

- **Events:** Ordered list from `data/events.yml` (dateISO for past vs upcoming; `null` = TBD date, still “upcoming”). **Within** the Upcoming and Past carousels, order is the file order of rows that fall into each bucket. Each event: image, title, subtitle, date, time, location, ticket link, description. Detail page at `/events/[slug]`. The Events block uses `ScrollReveal` with `freezeAfterReveal` so scroll-linked opacity does not fade the carousels out when leaving the section (avoids card flashing). In-view animations for cards use a one-way `hasRevealed` latch so leaving the intersection observer does not reset Framer `animate` to hidden. 3D tilt and image zoom run only for `(hover: hover)` and `(pointer: fine)`; image area keeps `bg-muted` under the photo to reduce loading flash.
- **Artists:** From `data/artists.yml`. Card: image, name, genre, bio, social links (Spotify, Apple Music, Instagram, etc.), optional featured track (Spotify or SoundCloud embed).
- **Services:** From `data/services.yml`. Display as defined in YAML (e.g. titles, descriptions, icons).
- **Partners:** From `data/partners.yml`; corporate row renders in `components/services.tsx` via `getPartners()`. Logos use a **responsive grid** (`grid-cols-2` / `sm:grid-cols-4`, `place-items-center`); each link is a fixed **`size-*` circle** with **`bg-card`**, **`border-2`**, `overflow-hidden`, and theme-specific **`.partner-logo-chip`** shadow (see `app/globals.css`). Mono marks use `.partner-logo`: **light** ≈ black ink on the card; **dark** ≈ softened white via `invert` + `brightness(0.93–0.94)` with opacities from `--partner-logo-opacity*`. Optional YAML `imageClassName` (e.g. `scale-[0.9]`) normalizes visual weight. Optional `logoTreatment`: `outline`, `solid`, `natural` (full-color, per-theme `brightness`/`saturate` tweaks). Use **`natural`** when the PNG is mostly a flat-filled shape (e.g. circular brand mark with gradient)—mono `brightness(0)` would render as a solid blob.

**UI/UX.** Fonts: Space Grotesk (sans), Inter (body), Playfair Display (serif). Pill CTAs (`.btn-metallic-gold` / `.btn-metallic-brass` and the hero outline pair) keep label text on **one line**; `--lupfr-pill-cta-fs` in `app/globals.css` uses a `clamp()` so type scales down on narrower viewports instead of wrapping. Theme support via `ThemeProvider` (next-themes). **Navigation** (`components/navigation.tsx`): fixed bar stays above the mobile full-screen drawer (`z-[60]` vs `z-[55]`); no Framer entrance on the bar (avoids fighting `transition-all` scroll styling). Mobile drawer locks `html`/`body` overflow while open, closes on `Escape` or backdrop click, uses safe-area padding and scrollable inner nav; section highlight uses a stable scroll-spy (last in-page section whose top crossed the offset). The hamburger control uses a 44×44px touch target. Desktop nav link highlights update on scroll via `requestAnimationFrame`-coalesced handlers. On viewports below `md`, the theme toggle sits in the fixed header beside the menu control. The menu/close icon uses `text-foreground` while the drawer is open (or when the header is scrolled) so the X stays visible on the light overlay in light mode; over the hero it stays white in light mode only when the menu is closed. Toasts (sonner) for form feedback. Contact and newsletter forms post to API routes; success/error surfaced in UI. Contact **inquiry type** chips include Book an Event, Corporate Event, Talent Booking, Submit Your Mix, Venue Partnership, Private Event, Sponsorship, and Other (`components/contact.tsx`).

**Assets.** Images under `public/`; YAML references paths from site root (e.g. `image: "/artists/name.jpeg"`). Social previews: `app/opengraph-image.tsx` and `app/twitter-image.tsx` generate PNGs (Satori) with the brand logo from `public/logos/will_logo.png`, wordmark line, and tagline; metadata and JSON-LD live in `app/layout.tsx`.
