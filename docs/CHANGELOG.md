### Fixed

- **Navbar section navigation no longer "takes forever to scroll".** Clicking a nav link to a deferred section (`#about`/`#team`/`#contact`) used to mount only the target, leaving the deferred sections above it as wrong-height placeholders — so the target's scroll position drifted while chunks loaded and a ladder of blind `setTimeout` realign retries (0–2200 ms in `home-page.tsx` plus 120/360 ms in `navigation.tsx`) chased the moving target for ~2s. New `lib/hash-scroll.ts` centralizes the behavior: `deferredSectionShouldMountForHash` mounts every deferred section at or above the target so it's positioned against real heights, and `realignHashTargetUntilStable` re-aligns across animation frames only until the position stops drifting (then stops — also on hash change away, user scroll, or a hard time cap). `components/navigation.tsx` drops its blind retry timers. Covered by `tests/unit/hash-scroll.test.ts`, `tests/components/deferred-home-section.behavior.test.tsx`, an updated `tests/unit/home-performance.test.ts` guardrail, and a new Playwright gate `scripts/verify-nav-scroll.mjs` (chunk-throttled, asserts each section lands flush under the header and settles fast).
